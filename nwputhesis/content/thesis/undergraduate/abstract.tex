\begin{abstract}
随着大语言模型和多模态感知技术的发展，服务机器人正逐渐从短时任务执行走向家庭服务、人机协作等长期连续部署场景。在这类场景中，机器人不仅需要完成当前任务，还需要持续记录和理解自身经历，并能够根据用户的自然语言问题回溯过去发生的事件。将机器人多模态经历组织为可检索、可问答的长期情景记忆，是提升人机交互可信度和长期协作能力的重要基础。然而，随着运行时间不断增长，长期记忆系统也面临更加突出的挑战：历史规模扩大导致检索成本上升，持续写入经历造成存储压力增加，感知或摘要错误一旦写入记忆后也难以及时修正。现有长上下文语言模型、检索增强生成和层级记忆方法虽然能够在一定程度上支持长历史问答，但对跨事件语义关联、长期存储管理和动态错误修正的支持仍然不足。

针对上述挑战，本课题主要研究面向长时具身问答的图增强检索与主动记忆维护方法主要工作如下：

（1）提出一种基于事件关联图的长历史记忆检索方法。该方法从层级记忆树中的事件节点自动构建包含时间、物体、位置、动作和因果关系的事件关联图，并通过语义种子召回、图邻居扩展和联合重排实现图增强检索。同时，系统将任务、物体、日期和时间邻居等信息封装为结构化检索工具，使智能体能够沿更加明确的结构化路径访问相关记忆。

（2）提出一种效用引导的渐进式记忆遗忘方法。该方法综合考虑事件的新近性、语义独特性和多信号重要性，对不同事件分配连续效用评分，并根据评分结果执行完整保留、去除原始多模态大对象或仅保留摘要的分级压缩策略。为降低关键证据被误删的风险，系统进一步引入对话豁免、失败豁免、目标边界保护和最低保留比例等安全机制。

（3）提出一种反馈驱动的记忆修正方法。该方法根据用户反馈构造纠错线索，通过错误定位、LLM 辅助最小化修正、传播检测和自动传播修正四个阶段，对记忆树中可能存在的错误事实进行定位和更新。针对直接改写底层感知数据可能破坏原始记录的问题，本文设计了非侵入式视图重定向机制，使修正后的摘要能够在检索和展示过程中优先生效，同时保留原始记忆内容及修正来源。

实验结果表明，GRAF-Mem 能在长时具身问答中提升检索效率，降低冗余记忆带来的存储压力，并为错误记忆提供可追溯的修正机制。本文工作为长期服务机器人构建可检索、可压缩、可修正的情景记忆系统提供了一种可行方案。
\keywordslist{长期情景记忆, 服务机器人, 图增强检索, 主动记忆维护}
\let\cleardoublepage\relax
\end{abstract}

% 英文摘要
\begin{engabstract}
With the development of large language models and multimodal perception, service robots are gradually moving from short-term task execution to long-term deployment in domestic, assistive, and human-robot collaboration scenarios. In such settings, a robot is expected not only to complete current tasks, but also to record, organize, and retrieve its past experiences in response to users' retrospective questions. Building long-term episodic memory that can support natural-language question answering is therefore important for trustworthy and persistent human-robot interaction. However, as the operating history grows, long-term memory systems face several challenges: retrieval becomes more expensive, continuously written experiences increase storage pressure, and perception or summarization errors are difficult to correct once they have been stored. Existing methods based on long-context language models, retrieval-augmented generation, and hierarchical memory structures can support long-history question answering to some extent, but they are still limited in cross-event association, long-term storage management, and dynamic memory correction.

To address these challenges, this thesis studies graph-enhanced retrieval and proactive memory maintenance for long-term embodied question answering, and proposes GRAF-Mem (Graph-Retrieval and Adaptive Forgetting Memory), a long-term episodic memory framework built upon a hierarchical memory tree. The framework introduces an event correlation graph as a unified structural index, and improves the memory system from three aspects: retrieval, compression, and correction. The main work is as follows.

(1) A graph-enhanced retrieval method based on event correlation graphs is proposed. The method automatically constructs an event graph from event-level memory nodes, with semantic edges representing temporal, object, location, action, and causal relations. It then performs retrieval through semantic seed recall, graph-neighbor expansion, and joint re-ranking. Structured tools for tasks, objects, dates, and temporal neighbors are also provided, enabling the agent to access relevant memories through more explicit structural paths. Experiments on the TEACh dataset show that, under the $|h|=100$ long-history setting, GRAF-Mem achieves 49.0\% semantic correctness and 75.0\% partial correctness, with an average prompt-token cost of 2.29K, improving both answer quality and context efficiency compared with the reference baseline.

(2) A utility-guided progressive forgetting method is proposed. The method evaluates each event by considering recency, semantic uniqueness, and multi-signal importance, and then applies different compression levels, including full retention, removal of raw multimodal objects, and summary-only retention. To reduce the risk of discarding important evidence, several protection mechanisms are introduced, including dialogue exemption, failure exemption, goal-boundary protection, and a minimum retention ratio. Under the TEACh $|h|=50$ setting, the conservative configuration achieves 5.26\% tree-structure compression while preserving answer consistency. The more aggressive configuration reduces the number of relations by 50.83\%, with over 61\% of events entering the summary-only level, while still maintaining identical final answers. Additional experiments on ARMARX data show that graph centrality helps preserve relation-rich events that are important for downstream question answering.

(3) A feedback-driven memory correction method is proposed. Given user feedback, the method constructs correction cues and updates erroneous memories through four stages: error localization, LLM-assisted minimal correction, propagation detection, and automatic propagation repair. To avoid directly modifying low-level perceptual records, a non-intrusive view redirection mechanism is designed, allowing corrected summaries to take effect during retrieval and display while keeping the original memory and correction source traceable. Controlled error-injection experiments show that the method can perform local correction of erroneous facts and detect related error propagation in scenarios such as continuous-frame contamination. End-to-end closed-loop experiments further verify the complete process from user feedback to improved subsequent answers.

Experimental results indicate that GRAF-Mem can improve retrieval efficiency in long-term embodied question answering, reduce storage pressure caused by redundant memories, and provide a traceable mechanism for correcting erroneous memories. This thesis provides a feasible approach for building long-term robotic episodic memory systems that are retrievable, compressible, and correctable.

\end{engabstract}
