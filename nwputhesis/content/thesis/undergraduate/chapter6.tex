\section{工作总结}

随着服务机器人从实验室演示走向长期、连续的家庭和工业部署，情景记忆语言化——将原始多模态经验流转化为可被自然语言问答检索的记忆——成为人机交互中的核心能力。然而，长期部署中的记忆系统面临三个根本性的技术张力：检索效率与不断增长的历史长度之间的矛盾、持续写入新记忆带来的存储膨胀、以及感知和理解偏差一旦写入便无法修正的持久化污染。现有的解决方案各有所长但无法同时应对这三个挑战：长上下文 LLM 方案面临二次计算开销和中间信息丢失问题；RAG 方案因纯文本相似度匹配而缺乏横向语义关联；层级记忆方案解决了 token 成本问题但在记忆的主动维护（压缩与修正）上仍是空白。

针对上述挑战，本文提出了 \textbf{GRAF-Mem}（Graph-Retrieval and Adaptive Forgetting Memory），一个在层级记忆树骨架上集成图增强检索、效用引导遗忘和反馈驱动修正的主动式长期记忆框架。核心设计哲学是：长期记忆系统不仅需要高效的检索机制（"记得准"），还需要主动的存储管理能力（"忘得好"）和错误修复能力（"改得对"）。GRAF-Mem 的三个模块通过共享同一个事件关联图数据结构实现协同，检索利用图边做邻居扩展以提升召回率，遗忘利用图中心性做重要性评分以指导选择性压缩，修正利用图邻居做传播检测以扩大修复覆盖面，使得图结构成为贯穿检索、存储和维护三条主动能力的统一信息基础设施。本文的主要工作和核心发现如下：

\textbf{（1）事件关联图与图增强检索（第三章）。}针对层级记忆树纯纵向检索在横向语义关联上的不足（RQ1），本文提出从 L2 事件节点自动派生包含时间相邻、共享物体、共位置、相似动作和因果关联五类边的事件关联图，以及"语义种子召回→图邻居扩展（查询意图感知的边类型选择）→联合重排（$\alpha \cdot \text{语义项} + \beta \cdot \text{图贡献项} + \gamma \cdot \text{深度奖励项}$）"的三阶段图增强检索流水线。同时，将记忆树中的任务、物体、日期等结构化信息显式化为七种可调用工具（task\_list、task\_lookup、object\_lookup、date\_lookup、event\_date\_lookup、temporal\_neighbor、action\_lookup），配合预处理缓存体系和执行护栏，使 Agent 在长历史上的搜索行为从"盲目自由展开"转变为"沿结构化路径精确命中"。在 TEACh 数据集上的实验结果表明：在 $|h|=100$（约 2–3 个月的模拟机器人活动）设置下，GRAF-Mem 达到 S\textsubscript{c} = 49.0\%、S\textsubscript{p} = 75.0\%、平均 prompt token 消耗 T = 2.29K；相比使用完整历史扁平化 ICL 的基线（S\textsubscript{c} = 34.0\%、T = 10.4K），语义正确率提升 15 个百分点，token 成本降低 78\%。更值得注意的是，当 $|h|$ 从 50 翻倍到 100 时，GRAF-Mem 的 S\textsubscript{c} 基本持平（48.0\% → 49.0\%），说明图增强检索在一定程度上抵消了历史增长带来的检索难度。机制分析表明，这一双重优势来自事件图的横向扩展（弥补纯文本搜索遗漏）、结构化工具的精确命中（降低盲目搜索的噪声）以及缓存护栏的成本剥离三者的协同。

\textbf{（2）效用引导的渐进式遗忘（第四章）。}针对长期运行中 append-only 记忆树存储线性膨胀的问题（RQ2），本文提出基于多维效用评分的渐进式遗忘。效用函数综合三个维度——新近性（Recency，基于艾宾浩斯遗忘曲线的指数衰减）、语义独特性（Uniqueness，基于兄弟节点间嵌入向量余弦距离）、多信号重要性（Importance，融合用户对话 0.35、动作异常 0.20、目标变化 0.10 和图度中心性 $0.35 \times \text{归一化度值}$）——对每个 L2 事件节点计算 $[0, 1]$ 的连续效用值。根据双阈值划分执行三级渐进压缩：Level 0（$\ge \theta_1$，完整保留）、Level 1（$[\theta_2, \theta_1)$，删除原始图像/音频大对象但保留全部文本）、Level 2（$< \theta_2$，仅保留自然语言摘要摘要文本和时间戳）。同时配备四重保护机制：对话豁免、失败豁免、Goal 边界保护和最低保留比例参数安全下限，确保在任何参数配置下关键证据不丢失。遗忘在图构建之前执行，形成"先筛后连"的管线协作。

在 TEACh $|h|=50$ 的 full 100/100 QA 实验上，Forget+Graph（保守配置）以 5.26\% 的树结构缓存压缩保持最终答案与基线 100/100 逐条完全一致；Level 2 / Summary-Retention（强压缩配置）进一步将关系数从 577,052 条削减至 283,721 条（50.83\%），超过 61\% 的事件进入仅保留高层摘要的 Level 2，且同样保持 full 100/100 的最终答案逐条一致。在实际部署中叠加原始多模态文件后，Level 1 和 Level 2 操作带来的绝对存储节省将远超此处树结构缓存的压缩比例。在 ARMARX 真实机器人数据上的补充验证中，图中心性引导的遗忘（medium\_graph）展现了从"删多少"到"选择性遗忘"的质变——在与普通效用遗忘（medium）同等 L0 保留数（71/117）的情况下，将 Level 2 事件从 23 个降至 10 个，mean relations 从 112.63 升至 130.22，并在 4 个 relation-sensitive 探针上从 0/4 跃升至 4/4（与完整记忆的 base 持平）。这直接验证了"忘什么比忘多少更重要"——图中心性使遗忘预算更精准地分配给了对后续问答真正重要的 relation-rich 枢纽事件。Level 2 的摘要保留机制使得长期存储的增长从 $O(N)$（所有事件全细节保留）趋近 $O(\log N)$（仅保留高层摘要），这是解决 append-only 记忆树在数月甚至数年部署中存储膨胀问题的根本途径。

\textbf{（3）反馈驱动记忆修正（第五章）。}针对 append-only 记忆架构中错误一旦写入便永久冻结并通过层级引用传播的问题（RQ3），本文提出四阶段修正管线——错误定位（双探针嫌疑度排序）→ LLM 辅助最小化修正（四元组输入 + "只修改错误部分"约束）→ 传播检测（时间邻居与错误指纹的余弦相似度）→ 自动传播（高置信度类比修正）——以及基于 Python 运行时动态属性的摘要覆盖机制，以非侵入、可逆、可追溯的方式实现了对记忆树中特定节点的运行时修正。配套的模拟反馈评测协议通过同 episode 内共享 history 的有状态问答闭环，验证了反馈闭环对系统行为的实质性影响（共享 history 本身即可导致 40\% 的答案差异）。

由于 Answer Judge 在自然评测中偏向保守且 GRAF-Mem 的多源检索机制降低了孤立错误的影响力，修正在自然问答中极少被触发。因此本文采用受控错误注入范式进行定量验证：（a）LLM 修正 100\% 成功，不仅正确纠正了注入的物体混淆错误（"fridge" → "cabinet"），还展现了语义层面的最小化修正能力（自然地去掉了 "lower" 修饰语）；（b）在匹配设计假设的连续视觉帧误识别注入场景下，传播检测以 100\% 召回率（4/4）发现所有被同一感知误差污染的连续帧；（c）端到端闭环验证确认了修正管线的全链路代码正确性，摘要覆盖属性通过 deepcopy 和序列化正确传递，Answer Judge 和修正管线入口逻辑正常执行。修正不频繁触发不是修正机制的缺陷，而恰是 GRAF-Mem 在"不犯错"方面做到足够好的体现——图增强检索的多源证据冗余已经在抑制单一节点错误的影响力，修正作为最后一道防线在用户直接反馈或系统性感知污染的场景中随时可用。

综合三个模块，GRAF-Mem 将长期情景记忆从静态的"存下来、搜得到"推进为主动的"维护好、可更新"。事件关联图作为三个模块共享的统一信息基础设施，分别提供检索扩展路径、遗忘保护信号和修正传播检测依据——这种"一图多用"的架构设计是 GRAF-Mem 区别于现有工作中每个模块独立设计的核心创新。

\section{未来展望}

尽管 GRAF-Mem 在检索、压缩和修正三个维度上均取得了可验证的进展，但长期机器人情景记忆作为一个系统性工程，距离在真实机器人上持续运行数月甚至数年的高可靠部署仍存在可改进的空间。以下从四个层面简要讨论未来的研究方向。

\textbf{表示层。}当前的事件关联图仅支持五种预定义的边类型，且边的构建规则（如共享物体的 Jaccard 阈值、相似动作的余弦相似度阈值）依赖人工设定。未来可以探索两个方向：一是引入更丰富的边类型——例如基于 LLM 推断的失败传播链（将一次失败事件与导致它的前置事件因果连接）、基于自然语言指令的意图关联（将用户指令与随后执行的具体操作连接）；二是自动化图结构搜索——借鉴神经网络架构搜索（NAS）的思想，在验证集上自动搜索最优的边类型组合和权重配置，以最大化检索召回率和压缩保护效果的联合指标。

\textbf{遗忘层。}当前的遗忘阈值 $\theta_1$ 和 $\theta_2$ 是全局固定参数，不根据实时的存储压力和任务负载动态调整。在实际部署中，机器人在某些时期（如搬家后、新用户入驻时）可能经历大量高信息密度的事件，而在日常例行维护期间事件的信息密度较低。未来的遗忘模块可以引入\textbf{自适应阈值调度}——根据当前记忆树的总大小、剩余存储预算和近期的 QA 频率动态调整 $\theta_1/\theta_2$，在存储压力大时自动提高压缩强度，在信息密度高的时期自动降低压缩强度。此外，\textbf{遗忘率的在线学习}也是一个可能的方向——从用户后续提问的频率和类型中学习哪些类型的记忆实际上更常被回溯，从而优化效用函数的权重分配。

\textbf{修正层。}当前的错误定位仅依赖文本嵌入相似度（单模态），而许多感知错误（如视觉场景图构建中的物体误识别）在文本层面可能没有明显的语义差异（"cabinet" 和 "fridge" 在嵌入空间中确实相似）。引入\textbf{多模态错误定位}——同时利用文本嵌入（摘要文本）和视觉嵌入（原始帧特征）进行嫌疑度计算——可能提升定位的精确度。另一个方向是\textbf{跨 episode 传播检测}，当前传播检测仅搜索同一 Goal 内的连续帧，但同一视觉误识别可能在机器人多次经过同一场景的数天后再次出现。跨 episode 的传播检测需要引入"场景指纹"的概念，通过位置签名和物体集合的相似度来判断两个时间上不连续但场景相似的事件是否可能受同一视觉识别的系统性偏差影响。

\textbf{部署层。}GRAF-Mem 当前的所有实验均在离线预处理数据上进行，Agent 通过 API 调用运行在云端。将 GRAF-Mem 集成到真实机器人堆栈（如 ArmarX 框架或 ROS 2 生态）中，在实时交互中验证记忆维护的闭环效果——特别是在修正模块接收用户自然语言反馈（而非模拟的 ground truth）的场景下——是推动该系统从学术验证走向工程实用的关键一步。此外，目前的评测仅覆盖了 TEACh（模拟家居）和 ARMARX（受控实验室环境），在更复杂、更不可预测的真实家庭环境中的长期部署，将为 GRAF-Mem 的鲁棒性和泛化性提供更严格的检验。
