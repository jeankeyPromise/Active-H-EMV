# 交互式测试命令

## 1. ARMARX 基础交互

```bash
set -a
source .env
set +a
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
python -m llm_emv --config armarx_lt_mem/full_gemini
```

说明：
- 默认读取 `data/armarx_lt_mem/2024-a7a-merged-summary.pkl`
- 适合做普通层级树交互测试

## 2. ARMARX 图结构交互

```bash
set -a
source .env
set +a
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
python -m llm_emv --config armarx_lt_mem/full_gemini_graph
```

说明：
- 在 ARMARX 交互式问答中启用 `graph_augment`
- 当前打开的图增强包括 temporal / co-object / co-location / similar-action
- 当前未启用 causal edge

推荐英文问题：
- `What did you do on August 27, 2024?`
- `What items were loaded into the dishwasher?`
- `Why did the first attempt to grasp the milk fail?`

## 3. TEACh 图结构交互

```bash
set -a
source .env
set +a
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
python -m llm_emv \
  --config teach/simplified/full_graph_aug_interactive \
  --teach-base dataset/TEACh \
  --teach-qa-file data/teach/test_set_5.pkl \
  --teach-sample-index 0
```

说明：
- 入口会根据 `test_set_5.pkl` 中第 `0` 个样本构造对应 TEACh history
- `--teach-sample-index` 可改成 `1`、`2` 等，切换不同交互 history
- `full_graph_aug_interactive` 已启用图增强检索，并关闭了 few-shot prompt 检索启动开销，更适合交互

## 4. TEACh 非图增强交互

```bash
set -a
source .env
set +a
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
python -m llm_emv \
  --config teach/simplified/full_gemini_2.5_pro_interactive \
  --teach-base dataset/TEACh \
  --teach-qa-file data/teach/test_set_5.pkl \
  --teach-sample-index 0
```

说明：
- 这一组可作为 TEACh 的非图增强交互基线
- `full_gemini_2.5_pro_interactive` 同样关闭了 few-shot prompt 检索启动开销

## 5. 通用自定义 history pkl 交互

```bash
set -a
source .env
set +a
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
python -m llm_emv \
  --config armarx_lt_mem/full_gemini_graph \
  --history-pkl /absolute/path/to/history.pkl
```

说明：
- 当你手头已经有预处理好的 `HigherLevelSummary` pickle 时，可以直接加载
- `--history-pkl` 优先级最高，会覆盖默认 ARMARX / TEACh 自动加载逻辑
