# 第二章 相关技术综述

## 2.1 引言

随着大语言模型与多模态感知技术的快速发展，服务机器人正逐步从实验室演示走向长期、连续的家庭部署。在这一趋势下，如何让机器人有效组织、检索和维护跨越长时间跨度的经历数据，成为情景记忆研究领域的关键挑战。本章围绕 GRAF-Mem 框架所涉及的技术领域，从机器人情景记忆、记忆检索与图增强方法、记忆压缩与遗忘机制、对话系统中的记忆修正四个方面回顾已有研究工作，分析其与本文的联系和差异。接着，本章对 GRAF-Mem 所基于的层级情景记忆框架进行介绍。最后简要说明本文实验所使用的评测基准。

## 2.2 机器人情景记忆

机器人情景记忆的表示方法经历了三个发展阶段。

**基于隐向量的方法** 将机器人的经历编码为固定维度的潜在向量。这类方法通常使用循环神经网络（RNN）或变分自编码器（VAE）对时序化的感知数据进行压缩编码，在检索时通过向量相似度匹配相关经历[1-4]。例如，文献[3]使用长短期记忆网络（LSTM）将机器人操作序列编码为情景向量，在后续任务中通过解码器重构相关经历；文献[4]进一步引入注意力机制，使编码器能够选择性关注经历中的关键帧。这类方法的优势在于检索效率高——向量匹配的复杂度与记忆库大小呈亚线性关系——且端到端训练使得编码器和下游任务可以联合优化。然而，隐向量方法的局限也十分显著：隐向量的语义不可直接阅读，用户和开发者无法检查"机器人记住了什么"；编码器针对特定任务和场景训练，当机器人遇到训练数据之外的新物体或新任务时，编码质量显著下降；固定维度的潜在向量在压缩信息时不可避免地丢失细节——一个 512 维的向量无法完整保留事件中涉及的时间、地点、物体属性、动作及状态变化等全部信息维度。

**基于显式符号存储的方法** 将经历表示为结构化的符号记录——如键值对、关系图谱或一阶逻辑命题——并通过基于规则的检索接口进行查询。代表性工作如 KnowRob[8] 构建了基于本体的机器人知识库，通过逻辑推理引擎支持对物体位置、任务状态和事件时序的查询；RoboEarth[9] 则提出了云端的机器人经验共享平台，不同机器人可以将自身经历以结构化语义地图的形式上传和检索。符号化方法的核心优势在于精确性和可解释性——检索结果是确定性的，推理链可追踪。但其最突出的瓶颈在于可扩展性：规则库和本体的构建高度依赖人工设计，当环境中的物体类别从几十扩展到数千、任务类型从预定义扩展到开放域时，手工维护知识体系的工作量呈指数级增长。此外，符号化方法难以处理自然语言中的模糊性和多义性——同一问题可能有多种语义等价的表述方式，而规则式检索无法灵活应对。

**基于自然语言表示的大模型驱动方法** 是近年来大语言模型的涌现能力开辟的第三条路径：将经历直接转化为自然语言文本，利用预训练 LLM 的语义理解和生成能力实现灵活的记忆检索和问答[10]。这种方法兼具隐向量方法的泛化性和符号化方法的可解释性——自然语言文本既能被机器通过嵌入向量进行语义计算，也能被人类直接阅读。代表性工作是层级情景记忆框架（Hierarchical Episodic Memory, H-EMV）[11]，它提出将连续经验流组织为五层树状结构：L0 层为原始多模态感知数据，L1 层为场景图，L2 层为事件摘要，L3 层为目标摘要，L4+ 层为递归生成的高层片段摘要。在检索阶段，H-EMV 训练 LLM Agent 以交互式树导航的方式检索证据——Agent 可沿父子关系展开节点查看细节、折叠无关分支、或使用语义相似度搜索定位相关节点。该方案在 TEACh（模拟家居）、Ego4D（自我中心视频）和 ARMAR-7（真实机器人）三个数据集上验证了可行性，用比完整历史扁平化送入 LLM 低约两个数量级的 token 成本，取得了可比或更优的语义正确率。

上述三阶段方法虽然在记忆表示和检索方面取得了显著进展，但在**记忆维护**方面仍是空白：H-EMV 及其同类层级记忆方案仅依赖树的纵向父子关系和文本相似度进行检索，缺乏跨节点的横向语义关联；记忆树是 append-only 的，不具备压缩或遗忘机制；摘要一旦由 LLM 生成便冻结，无法在运行时根据用户反馈进行修正。GRAF-Mem 正是在这一基座之上，引入事件关联图、效用引导遗忘和反馈驱动修正三层主动维护能力。

## 2.3 层级情景记忆框架

GRAF-Mem 是在层级情景记忆树的骨架上构建的。为了让后续章节的技术阐述有清晰的上下文，本节对 H-EMV 的数据结构与交互式记忆访问机制进行介绍。

**层级记忆树结构**。记忆树将机器人从部署开始的所有经历组织为五层，自底向上逐层抽象：L0 层为原始多模态感知数据，包括 RGB 图像、深度图、音频流和关节角度序列，是记忆树中最"重"的组成部分；L1 层为场景图，从图像中提取物体实例列表及其空间关系（如 "Mug_0 is in/on CounterTop_0"），为后续的物体检索和空间关系推理提供结构化依据；L2 层为事件摘要，将连续若干帧的感知和场景图组织为一个自然语言描述的事件——通常对应一个具体的操作动作（如 "Pickup(Mug_0)"）或一行用户语音（如 "make coffee"），这是记忆树中最细粒度的自然语言层；L3 层为目标摘要，概括完成一个子目标的连续事件序列，例如"制作一杯咖啡"可能包含取杯子→倒水→开咖啡机→倒咖啡→端给用户等 5-15 个 L2 事件；L4+ 层为高层片段摘要，由 LLM 递归概括生成——将相邻 Goal 按时间跨度（通常以天为单位）分组为 L4 节点，再继续向上合并直至生成覆盖整个记忆树的单一根节点摘要。

> **插图说明 2.2**：五层记忆树结构示意图。从左至右展示 L0（图像/音频帧）→ L1（场景图：物体+关系）→ L2（事件摘要："Pickup mug"）→ L3（目标摘要："制作咖啡"）→ L4+（高层片段摘要："早上完成厨房任务"）。用颜色和箭头标注各层之间的抽象方向与父子包含关系。

**交互式记忆访问**。层级记忆树的检索不是简单的"给定查询→返回结果"式被动匹配，而是 LLM Agent 在树上的主动交互式导航。Agent 工作在 Python 控制台环境中，可以调用一系列预定义的方法：`expand(idx)` 展开指定子节点查看下一层内容；`search(query)` 在当前节点及其子树中进行语义相似度搜索，返回最相关的子节点；`collapse_all_but(idx)` 折叠除指定节点外的其他子节点以保持树的深度可控；通过索引链（如 `history[2][1]`）可直接导航到深层节点。Agent 的核心决策循环是：收到用户问题 → 在根节点进行语义搜索 → 展开最相关的子节点 → 检查子节点的摘要和子节点列表 → 如果信息已足够则使用 `answer()` 输出最终答案，否则继续在更下层展开或跳转到其他分支搜索。这一循环模拟了人类在回忆时的逐层聚焦过程——先回想宏观的时间段，再逐步定位到具体事件。

这一交互式导航范式的优势在于：（1）token 经济性——Agent 仅在需要时展开特定节点的细节，对于长历史场景，未展开的树在 prompt 中仅占数千 tokens，远低于完整历史扁平化的数十万 tokens；（2）可解释性——Agent 的导航路径（"在根节点搜索'咖啡'→展开第 3 个子节点→在 L4 层找到相关摘要→进一步展开看 L3 细节"）构成了一条自然的解释链；（3）状态持续性——Agent 的展开/折叠操作是有状态的，同一会话内的多个连续问题可受益于前序问题的树展开状态。

H-EMV 为 GRAF-Mem 提供了数据组织骨架和交互式检索范式，但其存在三点关键不足：（1）检索仅依赖树的纵向父子关系和文本相似度，缺乏跨节点的横向语义关联——无法高效回答"这个杯子后来出现在哪些任务中"等需要跨分支追踪的查询；（2）记忆树是 append-only 的，不具备压缩或遗忘机制，在长期部署中存储开销和检索延迟将持续增长；（3）摘要一旦由 LLM 生成便冻结，无法根据后续交互反馈进行修正，而机器人在真实部署中不可避免地会产生感知误识别或摘要措辞偏差。GRAF-Mem 的三个核心模块正是针对这三项不足而设计。

## 2.4 记忆检索的图增强方法

基于向量相似度的记忆检索是当前大模型应用中最主流的检索范式，代表性框架为检索增强生成（Retrieval-Augmented Generation, RAG）[12]。其核心流程为：将记忆条目切分为文本块，使用嵌入模型（如 Sentence-BERT[13]）将各文本块编码为固定维度的稠密向量，构建向量索引（如 FAISS[15]）；检索时将查询编码为同维度向量，通过近似最近邻搜索（ANN）返回与查询最相似的 top-k 个文本块，送入 LLM 生成最终答案。为提升检索精度，近年来出现了多种改进方案，如 HyDE[16] 在检索前使用 LLM 生成假设性答案以缩短查询与文档的语义距离，Re-ranking[18] 在初步检索后使用更强的交叉编码器对候选结果进行精排。

然而，在机器人长期情景记忆场景下，纯向量检索面临两个核心挑战：（1）**措辞鸿沟**——同一事件或物体可能以完全不同的措辞被描述，例如用户问"那个蓝色的杯子"，而记忆中的相关事件可能仅描述为 "picked up a mug from the sink"，纯文本相似度无法跨越这种语义等价但词汇层面不相似的鸿沟；（2）**横向关联缺失**——向量搜索是 item-to-query 的独立匹配，返回的是离散的文本块列表，不携带任何块间关系信息，无法回答"这个杯子后来出现在哪些任务中"等需要沿时间线追踪同一物体跨任务出现记录的查询。

为弥补纯向量检索在结构化关联捕捉上的不足，近年来出现了多种将图结构引入检索流程的方法。知识图谱增强的 RAG（Graph RAG）[19] 在检索前利用知识图谱中的实体关系对查询进行扩展，例如从 "blue cup" 扩展至 "mug, cup, vessel" 等上位词/同义词，以提升召回率；层次化索引方法（如 RAPTOR[20]）将文档组织为聚类树，在不同层级上分别进行向量检索和文本生成，使检索结果既能覆盖宏观主题也能命中微观细节；在视频理解领域，VideoTree[22] 和 VideoAgent[23] 等工作也采用类似的"结构化索引 + LLM Agent 导航"范式，将长视频的帧序列组织为树或图，让 Agent 通过自适应展开定位关键帧。

然而，当前图增强检索方法的一个共同特征是：图结构多用于离线索引构建或可视化辅助，而非直接嵌入在线检索链路——检索仍以向量相似度为主，图仅作为辅助索引；图的边类型（实体共现、主题相似度等）是预设的通用关系，而非针对机器人场景定制。在机器人情景记忆场景中，事件之间天然存在时间相邻（同一目标下的操作序列）、共享物体（同一物体出现在多个任务中）、共位置（发生在家具/房间等同一空间位置）、相似动作（执行了相同或相似的操作）等多维语义关联，这为构建场景化的事件关联图并直接嵌入在线检索链路提供了独特机会。本文第四章将详细阐述这一方法的设计与实现。

## 2.5 记忆压缩与修正

**记忆压缩**。经典遗忘模型——艾宾浩斯遗忘曲线[24]——指出记忆保持率随时间呈指数衰减。在信息检索和数据库管理系统中，这一原则被广泛应用于缓存置换策略（如 LRU 及其变体）和时间窗口策略（如滑动窗口、衰减窗口），前者优先淘汰最近最少使用的条目，后者通过设置固定的保留时长阈值自动删除超过时限的数据。然而，这些经典策略在面对机器人情景记忆时存在明显不足：时间不是决定记忆价值的唯一因素——三周前的一次失败任务可能比三天前的一次成功例行操作对后续问答更重要；固定时间窗无法区分不同信息类型——图像等大对象应比文本更激进地压缩，但文本中的关键语义信息需要保留。

随着 LLM 上下文窗口的不断扩展，如何在有限上下文内有效管理长对话/长文档中的记忆信息成为研究热点。MemGPT[26] 提出了一种受操作系统虚拟内存管理启发的分层记忆架构——将 LLM 的上下文视为"主内存"，将外部存储视为"虚拟内存"，通过类似页面置换的机制在对话过程中自动将历史信息在主内存和虚拟内存之间换入换出。MemWalker[27] 将长文本组织为摘要树，在问答时让 LLM Agent 从根节点开始逐层导航至相关叶节点，与 GRAF-Mem 的树导航机制有相似之处，但其树结构是静态的且不支持压缩。LongMem[28] 则在 Transformer 解码器之上增加了一个侧边记忆模块，通过注意力机制实现对历史信息的软寻址和选择性遗忘。

这些工作在"有限资源内管理大量信息"这一核心问题上与本文有共同关注，但也存在关键差异：它们的管理对象是 LLM 上下文中的文本序列，而本文的管理对象是包含结构化的多模态层级数据（图像、场景图、关系列表等）的记忆树——压缩决策需要感知节点的数据类型和层级位置；此外，这些方法的记忆管理多服务于单次长对话中的"当前任务"而非跨越数周到数月的"长期知识"，因此缺少对新近性和重要性的联合评估机制。本文第五章将提出一种综合考虑时间衰减、事件重要性和信息类型的效用引导渐进遗忘机制。

**记忆修正**。对话系统中的错误修正主要有两条技术路线。第一条是基于用户反馈进行模型参数更新：在线强化学习[32] 将用户的正/负反馈作为奖励信号，通过策略梯度方法更新对话策略的参数；Active Retrieval[33] 等工作利用用户反馈信号调整检索查询的生成策略。这类方法的优势在于可以通过持续交互不断优化系统表现，但每次修正都需要经过模型推理和参数更新，计算成本高，且参数更新可能带来全局性的副作用。第二条是知识编辑（Knowledge Editing）[34]：代表性方法如 ROME[35] 和 MEMIT[36] 通过对 Transformer 前馈网络中的特定神经元（通常位于 MLP 层的中间层，被认为存储了事实性知识）进行精确的权重修改，实现对特定事实条目的定位和修正。这类方法的优势在于修改的精确性和局部性——理想情况下只改变目标知识而不影响其他知识。但在实际应用中，知识编辑仍面临泛化性不足（修改后的知识未必能在不同的提问方式下稳定输出正确回答）和副作用评估困难（难以穷举被修改神经元所影响的所有知识条目）等挑战。

上述修正方法均在模型参数空间或检索策略空间中操作，而本文面临的是一个不同的问题：在层级记忆树中，错误存在于**记忆数据**本身——某条摘要的措辞偏差、某个场景图中物体的误识别——而非模型的推理能力不足。因此，修正的目标是修改记忆数据条目而非模型参数。此外，记忆树中的错误具有**传播性**：L2 层的错误可能被 L3 层摘要引用，L3 层的错误进而被 L4+ 层的递归摘要放大，形成一个以原始错误为源头的污染网络。针对这两个特征，本文第五章将提出一种面向记忆数据的、条目级的、传播感知的修正机制。

> **表 2-2 对话系统修正方法对比**
>
> | 方法类型 | 修正对象 | 修正粒度 | 可逆性 | 传播感知 | 代表工作 |
> |---------|---------|---------|-------|---------|---------|
> | 参数修正（RL） | 模型参数 | 全局 | 低 | 无 | [32][33] |
> | 知识编辑 | 模型参数/神经元 | 局部 | 中 | 无 | ROME[35], MEMIT[36] |
> | **GRAF-Mem (本文)** | **记忆树摘要节点** | **条目级** | **高** | **有** | 本文 |

## 2.6 评测基准

本文的实验主要依托以下三个数据集，覆盖从模拟家居到真实机器人的多样化应用场景。

**TEACh**（Task-driven Embodied Agents that Chat）[37] 是一个模拟家居环境中机器人执行任务并进行自然语言对话的数据集。它基于 AI2-THOR 模拟器构建，覆盖厨房、客厅、卧室等多种家庭场景。数据集中每条 episode 记录了一个完整的人机交互任务流程：用户通过自然语言指令要求机器人执行特定任务（如 "make coffee""clean the plate"），机器人执行对应的动作序列（导航、拾取、放置等），期间包含用户的反馈性语音和系统 ASR 识别结果。TEACh 是本文最主要的评测平台，使用的长历史问答测试集包含 10 段长历史，每段历史由 5/15/50/100 个 episode 拼接而成（记为 |h| = 5/15/50/100）。每段历史配有 10 种不同类型的问答对（共 100 题），涵盖任务列表型（sequence_of_task_descs）、动作描述型（seq_specific_shortened_low_actions）、时序推理型（seq_right_after/before_questions）、物体判断型（seq_simple_object_yes_no）以及日期关联型（exact_time_to_episode、tasks_to_days_ago 等）。评测沿用 H-EMV 的指标：S_c（Semantic Correctness，语义完全正确率）、S_p（Semantic Partial，至少部分正确率）、T（平均 prompt tokens 每 QA）和 Valid Answer Rate（有效回答率）。

**ARMARX_LT_MEM** 收集自德国卡尔斯鲁厄理工学院 ARMAR-7 人形机器人的真实运行数据。数据覆盖约 3.3 小时的活动，跨越约 2 个月，包含 117 个高细节密度事件。与 TEACh 的模拟环境不同，ARMARX 数据来自真实物理世界——机器人执行的是真实的拾取、放置、导航和交互动作，视觉输入包含真实的光照变化、遮挡和物体杂乱摆放。在本文中，ARMARX 主要用于遗忘模块的机制验证——评估不同遗忘设置下的结构保真度和关键事件的保留情况。由于该数据集缺少完整的标准化 QA 评测集（原论文仅含 30 对 QA），本文在遗忘实验中使用结构审计（统计 L0/L1/L2 分布、mean scenes、mean relations）和局部细节切片来定量验证。

**Ego4D**[38] 是一个大规模自我中心（第一人称视角）视频数据集，由参与者佩戴头戴式相机在日常活动中录制。本文使用的子集包含两段长视频（合计约 11 小时），配有 40 对具有挑战性的 QA 对。由于第一人称视频的视角与机器人传感器回传的视角不完全一致，且动作和物体的标注同样依赖计算机视觉模型，Ego4D 对记忆系统的视觉理解能力提出了更高要求。本文主要将此数据集作为 GRAF-Mem 的跨领域泛化性验证。

> **表 2-3 本文使用的三个评测数据集概况**
>
> | 数据集 | 环境 | 数据时长 | Episode 数 | QA 规模 | 主要用途 |
> |--------|------|---------|-----------|--------|---------|
> | TEACh | 模拟家居 | 数周–数月（模拟） | 5–100/段 | 100 题/段 × 10 段 | 主评测平台 |
> | ARMARX_LT_MEM | 真实机器人 | ~3.3 小时 | 117 事件 | 30 QA + 4 probe | 遗忘机制验证 |
> | Ego4D | 人类第一人称 | ~11 小时 | 2 段长视频 | 40 QA | 跨领域泛化验证 |

## 2.7 本章小结

本章从机器人情景记忆的发展脉络出发，回顾了基于隐向量、显式符号存储和自然语言表示的三种记忆表示方法，分析了各阶段方法的优势与局限，引出了以 H-EMV 为代表的 LLM 驱动方法作为 GRAF-Mem 技术基座的合理性。在此基础上，本章对层级情景记忆框架的数据结构与交互式访问机制进行了专项介绍，并分别分析了记忆检索的图增强方法、记忆压缩与修正机制两个方向已有工作的不足。综合来看，现有工作在以下三个方面与本文存在显著差异，构成了 GRAF-Mem 的研究空间：（1）在记忆检索方面，现有图增强方法多将图作为离线索引或可视化工具，GRAF-Mem 将事件图直接嵌入在线检索链路，且图结构同时服务于遗忘和修正模块；（2）在记忆压缩方面，现有方法多为全或无删除或固定时间窗切分，GRAF-Mem 采用基于多维效用（时间衰减、事件重要性、信息类型）的三级渐进式软压缩；（3）在记忆修正方面，现有方法在模型参数或检索策略层面操作，GRAF-Mem 以条目级的、非侵入的、传播感知的方式对记忆数据进行修正。在后续第三章至第五章中，本文将分别对事件关联图、效用引导遗忘和反馈驱动修正三个模块的技术实现与实验验证进行详细阐述。
