# 第一章 绪论

## 1.1 研究背景

近年来，随着大语言模型（Large Language Models, LLMs）与多模态感知技术的快速发展，服务机器人正从实验室演示走向长期、连续的家庭和工业部署。不同于工业机器人在结构化环境中执行重复性精确操作，服务机器人需要在数周至数月的时间跨度内，与用户进行自然语言交互，理解环境动态，并完成多样化的日常任务。在此过程中，一个核心能力日益凸显：机器人不仅需要执行任务，更需要能够**回忆和讲述**过去的经历——回答诸如"上周三下午你做了什么""那个蓝色杯子后来放哪了""为什么那次任务失败了"等回溯性问题。这种将原始多模态经验流转化为自然语言问答的能力，被称为情景记忆语言化（Episodic Memory Verbalization, EMV），是提升人机交互信任感、可用性和长期协作效率的关键技术[1][2]。

实现长期情景记忆语言化面临三个根本性的技术张力。其一是**检索效率与历史长度的矛盾**：随着机器人持续运行，其累积的经历数据量不断增长，从数小时的单一任务到数月的多任务交互。如何在不断膨胀的记忆库中快速定位与当前问题相关的少数关键证据，而非将全部历史倾泻给语言模型，是决定系统能否在长期部署中保持响应速度和经济可行性的核心问题。其二是**存储开销与信息保真的矛盾**：持续写入新记忆必然导致存储增长。机器人每天的感知数据：RGB 图像、深度图、音频流、关节角度序列，若不加选择地全部保留，存储成本将随运行时间线性膨胀。但若简单按时间窗口丢弃旧数据，又可能丢失对回溯性问答至关重要的细节（如几周前某次失败任务的具体原因）。其三是**记忆固定性与错误修正需求的矛盾**：机器人的感知和理解模块：包括视觉场景识别、语音识别和 LLM 摘要，不可避免地会产生偏差或错误。在传统的 append-only 记忆架构中，这些偏差一旦写入记忆便成为"冻结"的事实，持续污染所有涉及该记忆条目的后续问答，且缺乏在不破坏原始数据的前提下进行修正的机制。

当前解决长历史记忆问答的路径主要包括三类。其一是**长上下文语言模型方案**[3][4]：利用具有超长上下文窗口（如 128K 至 1M tokens）的大语言模型，将机器人完整的历史记录直接作为 prompt 送入模型，由模型自身在全局上下文中进行推理和答案生成。这类方案的优势在于实现简单、无需预组织历史，但存在两个核心瓶颈：（a）Transformer 架构的自注意力计算复杂度随序列长度二次增长[5]，对于跨越数月的机器人运行数据（即使压缩为文本也动辄数十万 tokens），每次问答的计算开销将极为庞大；（b）大量研究[6][7]表明，长上下文模型在序列中段存在显著的"中间信息丢失"（lost-in-the-middle）现象，模型对上下文中间位置信息的利用效率远低于首尾位置。其二是**检索增强生成方案**（Retrieval-Augmented Generation, RAG）[8]：将历史切分为文本块并基于向量相似度检索与问题最相关的片段，仅将检索到的少量片段送入 LLM 生成答案。RAG 有效控制了 token 成本，但纯文本向量相似度在面对需要跨时间、跨任务进行横向关联的复杂回溯性问题时（如找出某物体在所有任务中的出现位置），容易遗漏关键证据，因为语义相关的证据可能使用了完全不同的措辞。其三是**层级记忆方案**：将机器人经历预组织为层级化的自然语言摘要结构[1]，Agent 以交互式展开/折叠/搜索的方式在层级树中导航检索证据。该方案在 token 成本控制上取得了显著效果：用比 flatten 方案低两个数量级的 token 成本取得了可比或更优的语义正确率，但其在记忆维护方面仍是空白：树结构仅提供纵向的父子包含关系，缺乏跨节点的横向语义关联；记忆只增不减，长期运行后树体积持续膨胀；摘要一旦生成便无法修正，误差会在层级结构中传播和放大。

> **插图说明 1.1**：长历史机器人记忆问答的三种技术路径对比示意图。左侧：长上下文LLM方案（完整历史→模型→答案）；中间：RAG方案（历史→向量搜索→检索片段→LLM→答案）；右侧：层级记忆+Agent方案（历史→层级树→Agent交互导航→答案）。需标注各方案的核心瓶颈。

在此背景下，本文提出 **GRAF-Mem**（Graph-Retrieval and Adaptive Forgetting Memory）——一个在层级记忆骨架上集成**图增强检索**、**效用引导遗忘**和**反馈驱动修正**的主动式长期记忆框架。GRAF-Mem 的核心设计哲学是：长期记忆系统不仅需要高效的检索机制（"记得准"），还需要主动的存储管理能力（"忘得好"）和错误修复能力（"改得对"）——正如人类记忆不仅能够回忆，还能够选择性地遗忘和纠正。具体而言，GRAF-Mem 在保留层级记忆树纵向结构的基础上，从事件节点自动派生包含时间、物体、位置、动作等多类语义边的**事件关联图**，并围绕该图结构构建三个协同模块：图增强检索利用图边进行横向邻居扩展以弥补纯层级搜索的不足；效用引导遗忘利用图中心性指导节点重要性评估以实现选择性的渐进式压缩；反馈驱动修正利用图邻居关系检测错误传播以实现"从点到面"的记忆修复。

## 1.2 服务机器人与长期情景记忆

服务机器人是一类在非结构化环境中为人类提供日常辅助的自主系统，其应用范围涵盖家庭养老[9]、医疗康复[10]、物流配送[11]和人机协作[12]等多个领域。根据国际机器人联合会（IFR）统计，2023 年全球服务机器人市场规模已超过 250 亿美元，其中家庭服务机器人占比超过 60%，且年增长率保持在 20% 以上[13]。

与工业机器人在固定工位执行预编程重复操作不同，服务机器人面临三个核心挑战。第一是**环境开放性**：家庭和办公环境不是为机器人设计的——物体的位置、外观和状态不断变化，光线、遮挡和背景噪音持续存在。第二是**交互自然性**：用户以自然语言而非编程指令与机器人交互，要求机器人理解不完整的、模糊的、指代消解依赖上下文的口语表达。第三是**任务多样性**：机器人可能需要从"做一杯咖啡"切换到"找到上周放在某处的遥控器"再切换到"为什么昨天清洁地板的任务没有完成"——这些任务跨越不同的时间尺度、涉及不同的物体和位置、需要不同类型的信息。

这三个挑战共同指向一个关键需求：服务机器人需要能够**回溯性地访问跨越长时间跨度的丰富经历**。在单次、短时的任务场景中，机器人可以仅依赖当前感知和工作记忆即可完成任务。但在长期部署中：当一个机器人在同一家庭中服务了数周或数月后，用户会自然地期望机器人能够回答关于过去的问题，正如他们会问其他家庭成员一样。这种"长历史情景记忆问答"（Long-History Episodic Memory QA）并非对短期记忆的简单扩展：当历史从数小时延长至数月时，检索空间扩大了数百倍，而相关证据的密度却急剧降低，一个典型的一小时 episode 可能包含数千帧感知数据和数十个交互事件，而其中与用户当前问题相关的可能仅有寥寥几条。

基于自然语言表示的大模型驱动方法为这一问题提供了新的可能。不同于将经历编码为固定维度潜在向量的端到端训练方法（检索效率高但可解释性差），也不同于基于显式符号键值存储的规则式方法（可解释但难以扩展到开放环境），基于自然语言的记忆表示兼具可解释性（人类和机器都能直接阅读）、泛化性（大模型的零样本/少样本能力）和可操作性（LLM Agent 可以直接以代码方式与记忆树交互）。在这一路线中，代表性工作是层级情景记忆框架[1]（Hierarchical Episodic Memory, H-EMV），它将连续经验流组织为五层结构——L0 原始感知数据（图像、音频、动作指令）、L1 场景图（物体列表及其空间关系）、L2 事件摘要（单个动作或简短交互的自然语言描述）、L3 目标摘要（完成一个子目标的事件序列）、L4+ 高层片段摘要（递归 LLM 摘要直至单一根节点）——并训练 LLM Agent 以交互式树导航（展开/折叠/搜索）的方式在树中检索证据。该方案在 TEACh（模拟家居）、Ego4D（自我中心视频）和 ARMAR-7（真实机器人）三个数据集上验证了可行性。

然而，H-EMV 以及更广泛的层级记忆方案在**记忆维护**维度上仍是空白，而这恰恰是长期部署中最关键的工程挑战。具体而言：（1）**检索层面**：树结构天然只表达纵向父子包含关系。面对"这个杯子后来出现在哪些任务中"这类跨越多个目标的横向关联问题，Agent 必须逐一展开相关节点的子分支进行暴力搜索，这既低效又容易遗漏；（2）**存储层面**：记忆树是 append-only 的。服务机器人每天产生海量多模态感知数据（以 5 fps 采集一小时即约 3.6 GB 的 RGB 图像），加上场景图关系、LLM 摘要文本和树结构元数据，所有数据不加选择地全部保留。若机器人持续运行数月甚至数年，仅原始感知数据的存储即可达 TB 级别，且每次 QA 都需要将完整的记忆树加载到内存中进行检索——这对长期部署而言是不可持续的；（3）**维护层面**：摘要一旦由 LLM 生成便无法修改，视觉场景图构建中的误识别（如将"sink（水槽）"误标为"countertop（台面）"）或 LLM 摘要中的概括偏差会永久写入记忆，并通过层级引用关系污染所有依赖该节点的上层摘要。文献[1]在讨论部分将"误差传播"列为首要限制。

GRAF-Mem 正是为解决这三个记忆维护维度的问题而设计的。它不是对 H-EMV 的替代，而是在层级树这一"骨架"之上增加了三层"肌肉"——事件关联图提供横向语义连接、效用引导遗忘提供选择性压缩、反馈驱动修正提供可逆的错误修复。

## 1.3 研究目的与研究内容

针对 1.1 节和 1.2 节所述的长期部署中情景记忆的三个核心瓶颈：检索层面的横向语义关联不足（RQ1）、存储层面的记忆持续膨胀（RQ2）和维护层面的错误持久化与传播（RQ3）——本文提出 **GRAF-Mem**（Graph-Retrieval and Adaptive Forgetting Memory），一个面向长期机器人经验问答的主动式层级情景记忆框架。GRAF-Mem 在保留层级记忆树纵向检索优势的基础上，引入三个相互协同的模块，分别对应三个研究问题：

**（1）事件关联图与图增强检索（第三章，对应 RQ1）**。针对层级树纵向检索在横向语义关联上的不足，本文提出从 L2 事件节点自动派生事件关联图，在不修改树存储结构的前提下，在树之上插入一层图索引。图节点继承事件的物体集合、动作标签、位置签名和时间范围，边类型涵盖时间相邻（时间相邻边）、共享物体（共享物体边）、共位置（共位置边）、相似动作（相似动作边）和可选的因果关联（因果边）。在检索阶段，语义种子召回后沿图边向邻近节点扩展，并通过联合重排将语义相关性和图结构信号统一纳入排序决策。同时，将树结构中的任务、物体、日期等结构化信息显式化为可调用工具（task_list、object_lookup、date_lookup、temporal_neighbor 等），配合预处理缓存体系和执行护栏（token 上限、checkpoint/resume、短对象防护等），使 Agent 在长历史上的搜索行为从"盲目自由展开"转变为"沿结构化路径精确命中"。

**（2）基于效用的渐进式遗忘（第四章，对应 RQ2）**。针对长期运行中记忆存储线性膨胀且无选择机制的问题，本文提出**效用引导的渐进式遗忘**（Utility-Based Progressive Forgetting）。对记忆树中每个 L2 事件节点计算综合效用值 `U(n) = α·Recency(n) + β·Uniqueness(n) + γ·Importance(n)`——其中新近性基于艾宾浩斯遗忘曲线的指数衰减模型，独特性衡量节点在兄弟节点中的语义不可替代性，重要性综合用户对话存在性、动作异常状态、目标变化标记和事件图度中心性四个信号。根据效用值将节点分为三个遗忘等级：Level 0（U ≥ θ₁，完整保留）、Level 1（θ₂ ≤ U < θ₁，删除原始图像/音频等大对象，保留全部文本表示）、Level 2（U < θ₂，清空 scenes、relations、objects 等底层细节，仅保留 自然语言摘要 文本和时间戳）。同时设置遗忘豁免规则（包含用户对话或失败状态的节点永不遗忘，每个 Goal 的首尾事件受保护）和安全下限机制（最低保留比例参数 确保不会因参数设置不当导致灾难性遗忘）。在管线中，遗忘模块在图构建之前执行，形成"先筛后连"的协作模式——遗忘后的精简树使图更小、边更稀疏、检索更聚焦。值得强调的是，遗忘模块的核心目标不是提高 QA 准确率（不应期望"忘了冗余信息反而答得更准"），而是在保持问答稳定性的前提下控制长期存储开销。

**（3）反馈驱动记忆修正（第五章，对应 RQ3）**。针对 append-only 记忆架构中错误一旦写入便永久冻结且通过层级引用传播的问题，本文提出**反馈驱动记忆修正机制**（Feedback-Driven Memory Correction）。核心设计是摘要覆盖机制（Summary Override）：以 Python 运行时动态属性（摘要覆盖属性）的方式覆盖原始摘要的展示和检索行为，同时保留底层数据和原始版本（原始摘要副本）以支持可逆和可追溯。修正管线包含四个阶段——① 错误定位：构造错误/正确双探针查询，对每个事件节点计算嫌疑度分数 `suspicion(n) = 0.6·sim(n, q+a_wrong) + 0.4·(1 - sim(n, q+a_correct))`，按嫌疑度降序确定最可能的污染源；② LLM 辅助最小化修正：修正 LLM 接收原始摘要+问题+错误答案+正确答案四元组，被指示"只修改可能错误的部分，保留其他信息"，避免对整个节点的不必要重写；③ 传播检测：从已修正节点出发，沿时间序列检查前后邻居的摘要与原始错误摘要的余弦相似度，标记疑似被同一感知误差污染的相邻节点；④ 自动传播：对高置信度（相似度 ≥ 0.8）的疑似传播节点自动执行类比修正。

三个模块共享同一个事件关联图数据结构，但从中提取不同的信号用于不同的目的——检索利用图边做邻居扩展以提升召回率，遗忘利用图中心性做重要性评分以指导选择性压缩，修正利用图邻居做传播检测以扩大修复覆盖面。这种"一图三用"的架构设计是 GRAF-Mem 的核心创新之一：事件图不是某个模块的附属品，而是贯穿检索、存储和维护三条主动能力的统一信息基础设施。

## 1.4 本文内容安排

基于 1.3 节所述的研究内容，本文的组织结构如下：

**第一章 绪论**。阐述服务机器人长期部署中情景记忆语言化的研究背景，分析长历史记忆面临的三个核心技术张力（检索效率、存储开销、错误修正），回顾现有技术路径（长上下文 LLM、RAG、层级记忆）的优势与不足，提出 GRAF-Mem 框架及其三个核心模块的总体设计思路。

**第二章 相关工作**。从机器人情景记忆、记忆检索与图增强方法、记忆压缩与遗忘机制、对话系统中的反馈学习与记忆修正、评测基准与数据集五个方面系统回顾与本文相关的研究工作，分析各方向与本课题的联系与差异，为后续章节的技术阐述提供背景基础。

**第三章 图增强检索与结构化问答**。详细阐述事件关联图的构建方法（五类边类型的定义、构建算法与密度控制策略）、图增强检索的三阶段流水线（语义种子召回→图邻居扩展→联合重排）以及结构化检索工具与执行护栏的设计。最后在 TEACh 数据集上报告长历史问答实验（|h|=50 和 |h|=100）的主结果和机制归因分析。

**第四章 效用引导的渐进式遗忘**。详细阐述效用函数三个分项（新近性、独特性、重要性）的设计动机与计算方法、三级渐进遗忘操作的定义与适用场景、遗忘豁免与安全机制、以及遗忘→图构建的先筛后连管线。在 TEACh |h|=50 上报告 Forget+Graph 和 Level 2 强压缩两档实验的存储压缩与答案一致性结果，并在 ARMARX 真实机器人数据上补充图中心性引导遗忘的结构审计与局部细节切片验证。

**第五章 反馈驱动记忆修正**。详细阐述四阶段修正管线（错误定位→LLM 辅助修正→传播检测→自动传播）的算法设计、摘要覆盖机制的非侵入实现原理及其在语义搜索和树展示两个消费端的集成方式、以及模拟反馈评测协议的设计。在受控错误注入范式下，分别验证 LLM 修正质量（L4+高层片段摘要节点 层 object_swap 注入）、传播检测有效性（L2事件摘要节点 层连续帧同源误识别注入）和端到端闭环（完整 修正评测模式 评测管线）。

**第六章 总结与展望**。总结全文的研究内容与核心实验发现，分析三个模块之间的协同关系，并展望未来在表示层、遗忘层、修正层和部署层的改进方向。
