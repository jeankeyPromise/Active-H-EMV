# 中期报告（不少于1500字）

## 一、论文工作任务与进度安排情况

本课题题目为“基于自适应层级情景记忆语言化的高效长时具身问答方法研究”。随着具身智能和人机交互技术的发展，机器人不仅需要完成即时的感知、规划与执行任务，还需要能够回忆和表达自身过去的经历。情景记忆语言化旨在使机器人将长期运行过程中积累的视觉、动作、语音、目标状态等多模态经验转化为人类可理解的自然语言，并进一步支持基于历史经验的问答与总结。这一能力对于家庭服务机器人、长期陪伴型智能体以及可解释具身智能系统具有重要意义。

开题阶段确定的研究基础是 H-EMV 框架，即利用层级化的情景记忆表示将低层原始感知与动作记录逐步抽象为高层自然语言摘要，再由大语言模型作为交互式代理按需展开历史树并回答用户问题。该方法相较于直接把全部历史输入模型具有明显的可扩展优势，但在长期具身场景中仍存在若干不足：其一，原始树结构主要表达纵向时间层级关系，跨任务、跨日期和跨物体的横向语义联系较弱；其二，记忆树随运行时间不断膨胀，缺乏主动的记忆巩固和遗忘机制；其三，一旦摘要或感知信息中出现错误，错误容易在后续检索和问答中被反复继承；其四，完全依赖大语言模型逐层探索会带来较高的 token 消耗和响应延迟。因此，本课题的核心任务是在保持 H-EMV 层级记忆可解释性与接口兼容性的基础上，引入主动增强机制，形成更加高效、可维护、可修正的长期机器人经验问答系统。

根据开题报告，课题原计划分为文献调研与总体方案设计、原系统复现与初步测试、增强记忆表示与遗忘模块实现、检索与修正模块完善、实验分析与论文撰写等阶段。具体而言，1 月下旬至 2 月上旬主要进行文献调研、系统架构设计和模块接口定义；2 月中下旬完成原 H-EMV 在模拟数据上的初步运行验证；2 月下旬至 3 月底实现增强型层级记忆表示和离线记忆巩固与遗忘机制，并开展实验；3 月底至 4 月中下旬继续完成高效检索和自适应修正模块；4 月下旬至 5 月上旬分析实验数据、优化实验方案；5 月完成论文撰写，6 月准备毕业答辩。

截至中期检查阶段，本课题已完成较为系统的前期开发与验证工作。首先，已完成对原 H-EMV 项目结构、数据流程和评测流程的梳理，明确了原始系统的层级记忆构建、交互式历史访问、问答生成和自动评测方法，并在此基础上恢复了当前服务器环境，完成了依赖配置、数据路径整理和 TEACh 数据集基础读取流程验证，为后续实验提供了可运行的工程基础。其次，已围绕“自适应层级情景记忆语言化”的目标完成了四个核心方向的初步实现：增强型层级记忆表示、离线记忆巩固与遗忘机制、在线图增强检索机制以及闭环反馈与记忆修正机制。

在增强型层级记忆表示方面，当前系统在原有层级时间树之外引入了由事件摘要自动派生的记忆图结构。该图以事件级记忆为节点，并根据时间邻接、共现物体、共现位置、相似动作等关系建立横向边，使系统不再只依赖父子层级结构进行访问，而能够在检索阶段利用事件之间的语义和情景关联。该设计与开题报告中“情景-语义双层存储架构”的设想基本一致，并进一步明确为“树作为记忆骨架、图作为横向检索索引”的实现路线。

在离线记忆巩固与遗忘方面，已完成基于记忆效用的渐进式遗忘机制。该机制综合考虑事件的新近性、语义独特性和结构重要性，对低价值记忆进行分级压缩：重要节点完整保留，中等价值节点去除高开销细节，低价值节点保留轻量摘要。与开题时设想的简单聚类合并相比，当前方案更加保守，重点避免破坏原有层级结构和检索接口，同时通过豁免规则保护包含用户交互、异常状态或关键任务边界的记忆。该模块已完成局部验证，能够在压缩后保持摘要信息可被检索与展示，为后续存储效率实验奠定基础。

在在线检索方面，当前系统已由原始向量相似度检索进一步扩展为“初始语义召回、图邻居扩展、联合重排”的图增强检索流程。系统先根据查询得到初始候选事件，再沿记忆图扩展一阶邻居，将与初始候选存在物体、位置、动作或时间关联的事件纳入候选池，最后综合语义相似度和图结构得分进行排序。该机制已经通过小样本端到端测试和调试日志验证，能够在真实数据流程中把图上的相关邻居拉入候选集，初步解决原始树结构横向语义召回不足的问题。同时，历史实验记录显示，图增强零样本配置在一定规模的 TEACh 评测中具有较低的 token 消耗和较快的运行速度，说明该方向具有继续优化的价值。

在闭环反馈与记忆修正方面，已初步实现基于错误定位、摘要修正和传播检测的修正流程。针对早期评测中容易把自然语言摘要误判为错误的问题，当前系统已升级为“本地快速判断 + 语义判别”的混合判定策略：当回答与标准答案完全一致或互相包含时直接视为正确，否则调用语言模型从语义层面判断回答是正确、部分正确还是错误；只有在明确错误时才触发记忆修正。这一策略避免了单纯依赖字面重合度指标造成的误修正，较好地适配了具身动作摘要和自然语言描述之间表达方式差异较大的特点。该模块已经完成小样本 API 烟测，能够在语义部分正确时跳过修正，在明显错误时进入修正流程。

总体来看，当前进展与开题计划基本对应：原系统复现、环境恢复、数据读取、核心模块实现和小样本验证均已开展；增强记忆表示、遗忘、检索、修正四个方向已经具备可运行原型。与原计划相比，目前主要欠缺的是统一口径下的大规模稳定实验、消融对比和参数优化，尤其是各模块组合后对正确率、token 消耗和运行效率的系统分析。因此，本课题目前处于“核心框架已形成、功能原型已打通、实验体系仍需完善”的中期状态，后续工作的重点将从功能实现转向稳定评测、效果优化和论文整理。

## 二、论文相关资料查阅情况

围绕本课题，前期主要查阅和参考了机器人情景记忆、机器人经验语言化、长时具身问答、检索增强生成、视频理解与记忆巩固等方向的文献和技术资料。首先，H-EMV 论文是本课题的直接理论和工程基础。该工作提出将机器人长期经验组织为多层次树形结构，并通过大语言模型进行交互式历史探索，证明了层级摘要在长期经验语言化中的可行性。本课题在理解其层级表示、动态展开、按需检索和 TEACh 等数据集评测方式的基础上，进一步分析其局限，并将改进重点放在横向语义关联、记忆维护和反馈修正上。

其次，机器人情景记忆相关资料为本课题提供了记忆系统设计依据。显式符号存储、神经记忆模型和文本化记忆表示各有优缺点：神经模型具有端到端学习能力但可解释性不足，符号系统便于推理但扩展成本较高，文本化记忆适配大语言模型但容易受到上下文窗口和检索效率限制。本课题选择在文本化层级记忆基础上进行增强，是因为它既保留了自然语言摘要的可解释性，又便于与大语言模型、向量检索和图结构相结合。

再次，检索增强生成和向量检索相关资料对在线检索模块产生了直接影响。Dense Passage Retrieval、Sentence-BERT、Faiss 等工作说明，预先构建语义向量索引能够有效降低大规模文本检索成本；交叉编码器重排方法则为复杂语义匹配提供了更精细的判别思路。结合项目实际情况，当前实现优先采用轻量的语义召回和图结构重排，而将更复杂的交叉编码器训练作为后续可扩展方向。这样的选择兼顾了中期阶段的工程可行性和论文创新叙事。

此外，视频问答和具身数据集相关资料为实验设计提供了支撑。TEACh 数据集包含模拟家庭环境中的任务、动作、对话和视觉状态，适合验证具身机器人在长历史下的问答能力；Ego4D 等第一人称视频数据集则提供了真实长时视觉经验理解的参考。通过查阅这些资料，本课题明确了自身与普通视频问答的区别：机器人情景记忆不仅需要理解视觉内容，还要保留动作执行、任务目标、时间顺序和用户交互信息。

最后，认知科学中的遗忘曲线、睡眠记忆巩固、检索练习等理论为遗忘与巩固模块提供了启发。当前系统中的记忆效用评分借鉴了时间衰减和重要性保留思想，同时结合具身任务中的用户交互、异常状态和结构中心性等信号，形成更适合机器人经验问答的记忆维护策略。总体而言，相关资料不仅支撑了课题背景和方法选择，也直接影响了系统中图增强检索、渐进式遗忘和反馈修正等关键模块的设计。

## 三、存在问题及采取的措施

目前课题虽然已经完成核心原型，但距离最终论文和稳定实验仍存在若干问题。第一，系统的大规模评测尚不充分。已有历史实验记录表明，图增强零样本配置在部分设置下具有较低的 token 消耗和较快速度，但最近一轮长历史实验受到 API 稳定性、空回复和网络中断影响，未能形成完整、可作为正式结论的评测结果。因此，当前不能简单把中断实验作为论文主结果。后续将采取分层实验策略：调试阶段优先使用较小历史长度和较少问题数进行快速验证，减少无效 token 消耗；论文正式实验再在统一配置、统一评测口径和可复现实验记录下完成。对于每次实验，将保存原始输出、自动评测结果和 token 统计，避免混淆样本数与长历史规模。

第二，图增强检索的准确率提升仍需进一步优化。当前系统已经实现了真实的图邻居扩展和联合重排，但图结构能否稳定提升最终问答正确率，还受边类型选择、邻居数量、图得分权重、初始召回质量和大语言模型搜索策略影响。如果扩展过弱，图无法召回被树结构割裂的相关事件；如果扩展过强，又会引入过多噪声，增加模型探索成本。针对这一问题，后续将围绕不同边类型开展消融实验，分别比较时间边、物体边、位置边和相似动作边的贡献；同时调整邻居扩展数量和重排权重，记录每个问题的初始候选、扩展候选和最终返回节点，从而分析图检索失败的具体原因。

第三，遗忘机制仍缺乏系统性效果验证。当前渐进式遗忘模块已经能够在局部测试中保持压缩后摘要可检索，但尚未充分证明其在不同遗忘强度下对问答正确率、检索效率和存储开销的影响。遗忘参数若设置过激，可能导致关键细节丢失；若设置过保守，则难以体现存储压缩优势。后续将采用“保守默认、逐步增强”的实验策略，先验证低强度遗忘不破坏问答流程，再逐步提高遗忘比例，观察正确率和 token 消耗变化。同时，对包含用户对话、失败状态和任务首尾事件的节点继续设置保护规则，降低误删重要记忆的风险。

第四，反馈修正机制仍需控制误触发和错误传播风险。早期使用字面重合度作为答案判定依据时，容易把自然语言概括性回答误判为错误，从而可能污染记忆。当前已通过语义判别策略缓解该问题，但在真实实验中仍需关注语言模型判定不稳定、API 失败回退以及错误修正影响后续问题等情况。后续将继续采用保守触发原则，即只有在明确错误时才修正，部分正确或信息冗余时不修改记忆；同时保留原始摘要和修正摘要的对照记录，便于人工检查和论文案例分析。对于传播修正，优先进行检测和标记，待小样本验证充分后再扩大自动修正范围。

第五，工程运行成本和实验效率仍是现实限制。当前系统依赖外部大模型接口，长历史评测会消耗较多 token，且网络中断、空回复、无效检索命令等问题会导致成本浪费。为解决这一问题，后续将把开发阶段的主要测试规模控制在较小历史长度上，仅在关键节点运行较大规模实验；同时加强缓存、失败重试、输出清理和异常统计，尽量减少重复调用。对于论文最终结果，将优先报告正确率、部分正确率、token 消耗和运行时间等能够反映系统实用性的指标，而不只依赖 BLEU、ROUGE 等字面指标。

第六，论文写作与实验叙事仍需进一步统一。开题报告中部分预期目标包含交叉编码器微调、增量聚类、长期多数据集验证等较完整设想，而当前中期实现更强调图结构增强、效用遗忘和反馈修正的可运行原型。后续论文写作需要以当前真实完成内容为准，避免把尚未完成的训练或大规模实验写成既有成果。对于开题中尚未完全落地的部分，可作为后续改进方向或扩展实验进行说明，使论文表述既体现创新性，又保持客观可信。

## 四、下一阶段论文工作安排

下一阶段工作将围绕“稳定实验、优化系统、完成论文”三个方面展开。首先，在实验方面，将优先整理并固定评测口径，明确长历史规模、问答数量、正确率统计和 token 统计之间的关系，避免将调试样本数与历史长度混淆。开发阶段主要采用较小历史长度进行快速迭代，确认图检索、遗忘和修正模块在不同配置下均能稳定运行；在系统稳定后，再选择关键配置进行完整评测，形成可用于论文对比的结果表格。

其次，在图增强检索方面，将继续优化候选扩展和重排策略。计划针对不同查询类型分析图边作用，例如物体相关问题重点考察共物体边，地点相关问题重点考察共位置边，动作序列问题重点考察时间邻接边和相似动作边。通过消融实验确定哪些边类型真正带来正确率提升，哪些边会引入噪声。同时，将整理若干典型案例，展示原始树检索无法直接找到的相关事件如何通过图邻居扩展进入候选池，从而增强论文中方法有效性的可解释性。

再次，在遗忘与修正方面，将开展更细粒度的小规模验证。遗忘模块重点比较不同阈值下的压缩程度、问答正确性和检索轮数变化，确认“减少冗余而不损害关键记忆”的边界；修正模块重点验证语义判别策略是否能够减少误触发，并观察一次修正是否能改善同一历史中后续相关问题的回答。对于风险较高的自动传播修正，将先保留为受控实验，不在缺乏证据的情况下扩大到全部评测。

最后，在论文撰写方面，将根据当前项目实际进展完成论文主体框架。绪论部分重点阐述长期机器人经验语言化的背景、H-EMV 的优势与不足；方法部分围绕主动层级情景记忆框架展开，分别描述图增强检索、效用引导遗忘和反馈驱动修正；实验部分报告复现实验、图增强实验、消融实验以及 token 消耗分析；总结部分客观说明当前系统的局限和未来改进方向。5 月上旬完成主要实验和图表整理，5 月中旬完成论文初稿，5 月下旬进行修改完善、格式检查和答辩材料准备。
