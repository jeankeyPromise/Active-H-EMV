# 实验章节草稿

本文实验围绕三个问题展开：第一，图增强检索是否能够在长期情景记忆问答中提升语义正确性；第二，引入横向图结构后，系统的 prompt token 成本是否仍可接受；第三，Active-H-EMV 中的结构化 guardrail、遗忘与修正模块能否为长期记忆系统提供可解释的稳定性支撑。

## 1. 实验设置

实验基于 TEACh 长期机器人经验问答数据。每个 `|h|` 表示一段长历史包含的基础情景数量，例如 `|h|=50` 表示每段长历史由 50 个基础情景组成。标准评测文件包含 10 段长历史，每段 10 个问答，共 100 个 QA。调试阶段使用 `--n-samples` 截断前若干 QA，但该参数只表示 QA 数量，不等同于 `|h|`。

主要对比方法包括：

- H-EMV baseline：原始层级情景记忆检索与问答框架。
- Graph-H-EMV：在 H-EMV 层级树外构建事件图，执行“语义种子召回、图邻居扩展、联合重排”的图增强检索。
- Active-H-EMV diagnostic：在 Graph-H-EMV 基础上加入日期、任务、对象等结构化 guardrail，并使用 h=15 小样本验证稳定性。

本文主指标为：

- `S_c`：语义完全正确率，由 LLM judge 按类别评估后折算。
- `S_p`：部分正确率。
- Valid：有效回答率，即非空、非错误回答比例。
- `T`：每个 QA 平均 prompt token，单位为 K。

BLEU、ROUGE、METEOR 等表面重合指标只作为辅助参考，不作为核心结论依据。

## 2. 主结果

表 1 汇总了已跑满 100 QA、且有可追溯 auto-eval 文件的正式结果。

| 方法 | \|h\| | Shot | Valid | `S_c` | `S_p` | `T` |
| --- | ---: | --- | ---: | ---: | ---: | ---: |
| H-EMV baseline | 50 | few-shot | 96.0% | 41.0 | 27.0 | 27.63 |
| Graph-H-EMV | 50 | zero-shot | 100.0% | 43.0 | 23.0 | 5.19 |
| Graph-H-EMV | 50 | few-shot | 98.0% | 44.0 | 23.0 | 16.15 |
| H-EMV baseline | 100 | zero-shot | 90.0% | 42.0 | 27.0 | 7.08 |
| H-EMV baseline | 100 | few-shot | 95.0% | 38.0 | 21.0 | 29.85 |

在 `|h|=50` 上，Graph-H-EMV 相比 H-EMV baseline 的完全正确率从 41.0 提升到 43.0/44.0。尤其是 zero-shot Graph-H-EMV 在保持 100% 有效回答率的同时，将平均 prompt token 控制在 5.19K，明显低于 few-shot baseline 的 27.63K。这表明图增强并不只是增加上下文，而是通过更有针对性的候选扩展减少了无效展开。

few-shot 设置没有稳定带来收益。Graph-H-EMV few-shot 的 `S_c` 比 zero-shot 高 1 个百分点，但 token 成本从 5.19K 增加到 16.15K；H-EMV baseline 在 `|h|=100` 下 few-shot 反而低于 zero-shot，且 token 成本显著上升。因此，本文后续更倾向将 zero-shot Graph-H-EMV 作为主要推荐配置。

需要注意的是，当前 `|h|=100` 只有 baseline 可追溯正式结果，尚无跑满 100 QA 的 Graph-H-EMV 对照。因此，本文不能声称图增强已经在 `|h|=100` 上完成验证，只能将其作为后续工作。

## 3. 小规模稳定性诊断

为了验证 Active-H-EMV 的 guardrail 是否降低无效搜索和空回答，本项目在 `data/teach/test_set_15.pkl` 上进行了 h=15、`--n-samples 15` 的诊断实验。结果如下：

| 实验 | QA | Valid | `S_c` | `S_p` | `T` |
| --- | ---: | ---: | ---: | ---: | ---: |
| Active-H-EMV h=15 diagnostic | 15 | 100.0% | 46.7 | 20.0 | 2.70 |

该结果不作为论文主表中的正式规模化结论，但说明结构化 task/date/object 工具能够在小样本中显著降低 prompt token，并消除空回答。后续新增 helper `scripts/evaluate_result.sh`，用于在 h=15 n=15 这类实验完成后立即运行 correctness evaluation 和 `calc_metrics --primary-only`。

## 4. 消融观察

图增强的核心消融是 baseline 与 Graph-H-EMV 的对比。在 `|h|=50` 上，Graph-H-EMV zero-shot 相比 baseline few-shot 同时带来更高 `S_c`、更高 valid rate 和更低 token 成本。这说明图邻居扩展并非简单堆叠更多文本，而是提升了检索候选的相关性。

另一个消融是 zero-shot 与 few-shot 的对比。Graph-H-EMV few-shot 相比 zero-shot 的 `S_c` 仅提升 1 个百分点，但 token 成本约增加 3.1 倍。因此，在当前 API 稳定性和成本限制下，zero-shot Graph-H-EMV 更适合作为主配置。

日期、任务和对象 guardrail 的消融采用 h=15 targeted 证据。`task_list()` 将任务列表问题从多轮展开和空回复风险降低到单次结构化候选；`object_lookup()` 对无记录对象直接返回 negative answer；`event_date_lookup()` 将 `When did you water the plant?` 从错误的相对日期回答修复为具体日期回答。

## 5. 案例分析

### 5.1 图邻居扩展帮助召回

在 `graph_trace_h15_direct_search.jsonl` 中，查询 `sliced tomato` 时，基础语义检索首先命中 March 10/11 的沙拉相关任务。图增强检索随后通过 `similar_action` 边扩展到另一段历史，补充 March 15/16 的早餐与植物浇水任务候选。类似地，查询 `cook potato` 时，系统从 March 14 的土豆切片任务出发，通过 `co_object` 边扩展到 March 13 的完整餐食准备任务。这说明记忆图能够将跨天但共享动作或对象的事件拉入候选池，弥补树结构只强调父子层级的不足。

### 5.2 无记录问题提前停止

在对象存在性问题中，查询 `armchair` 时，`object_lookup('armchair')` 没有在 task-sized summaries 中找到匹配项，系统直接给出 “No, I have no record of that.”。这避免了继续搜索同义词、展开无关节点或调用 VQA，从而减少无效 token 消耗。该案例体现了 Active-H-EMV 的保守式回答策略：当文本记忆中没有可靠证据时，系统倾向于明确承认无记录，而不是生成貌似合理但无依据的答案。

### 5.3 时间事件结构化回答

在 `When did you water the plant?` 案例中，早期系统会把 faucet-only 事件误匹配为 watering，并回答相对天数。修复后，`event_date_lookup()` 对 plant query 增加对象约束，只保留包含 plant/houseplant 的事件，并根据问题类型返回具体日期。最终答案为 March 13th、March 15th 和 March 16th，auto-eval 从 wrong 变为 correct，prompt token 为 1.72K。

### 5.4 修正与遗忘模块

反馈修正模块通过本地 exact/substring 判断和 LLM semantic judge 混合触发，只有当回答被判定为 `WRONG` 时才执行摘要覆盖，避免把部分正确或信息冗余的答案误修正。遗忘模块则基于 recency、uniqueness、importance 计算节点效用，并用图度中心性衡量结构重要性。当前这两个模块已有 smoke 级验证，论文中适合以机制和闭环案例展示，不应夸大为已完成大规模量化验证。

## 6. 威胁与限制

第一，API 网关不稳定会导致空回复、连接错误和 judge timeout，因此实验采用 checkpoint/resume 和 failed-only retry。第二，h=15 cache 在后续长历史中仍存在缺失，若强行扩展到 n=50 会触发在线 summarization 并带来隐藏 token 成本。第三，Graph-H-EMV 缺少 `|h|=100` 的正式 100 QA 结果，因此本文的图增强量化结论主要建立在 `|h|=50`。第四，遗忘与修正模块目前以 smoke 和案例验证为主，尚未进行昂贵的大规模消融。

总体而言，实验结果支持以下谨慎结论：图增强检索能够在 `|h|=50` 长历史问答中提升语义正确率并显著降低 prompt token；结构化 guardrail 能在 h=15 诊断集中减少无效搜索和回答失败；效用遗忘与反馈修正为主动长期记忆提供了可解释机制，但仍需要更大规模实验证明其整体收益。
