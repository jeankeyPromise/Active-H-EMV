# 《项目整体架构与论文初稿大纲》

## 1. 摘要 (Abstract)

原版 H-EMV 以层级树表示机器人长期经验：从原始感知、场景图、事件摘要、目标摘要到更高层生活片段摘要，形成可被 LLM 逐层展开和检索的情景记忆结构。该设计保留了时间层级与叙事可读性，但也暴露出三个关键瓶颈：第一，树结构主要表达纵向父子关系，跨任务、跨时间的横向语义关联较弱；第二，长期运行下记忆树持续膨胀，低效或冗余节点会稀释检索质量；第三，摘要或感知错误一旦写入记忆，后续问答会持续继承该错误，形成误差传播。

本项目 Active-H-EMV 在不破坏原 H-EMV 层级树骨架的前提下，引入“图增强检索、效用引导遗忘、反馈驱动修正”三类主动机制。其核心思想可概括为“一图三用”：记忆图既作为横向语义召回索引，又作为遗忘模块的结构重要性依据，还可扩展为修正模块中的错误传播追踪结构。系统由被动存储式记忆，转向可检索、可巩固、可修正的主动情景记忆框架。

## 2. 核心架构与创新点解析 (Core Architecture & Innovations)

### 2.1 原始 H-EMV 层级记忆骨架

项目的基础记忆结构定义在 [em_tree.py](/home/user22303471/Project/Active-H-EMV/em/em_tree.py)。当前实现保留了 H-EMV 的 L0-L4 层级：

| 层级 | 代码类 | 学术含义 |
|---|---|---|
| L0 | `RawDataInstant` | 原始多模态瞬时经验：图像、声音、ASR、动作、目标状态 |
| L1 | `SceneGraphInstant` | 物体、关系与场景图文本化表示 |
| L2 | `EventBasedSummary` | 局部动作事件摘要，记忆图节点主要建立在这一层 |
| L3 | `GoalBasedSummary` | 面向任务或目标的事件序列摘要 |
| L4 | `HigherLevelSummary` | 跨任务、跨时间段的高层生活经验摘要 |

交互层由 [interactive_tree.py](/home/user22303471/Project/Active-H-EMV/llm_emv/interactive_tree.py) 和 [emv_api.py](/home/user22303471/Project/Active-H-EMV/llm_emv/emv_api.py) 包装为可展开、可折叠、可语义搜索的树。LLM 在问答时不是一次性读取全部历史，而是通过 `history.search(...)` 与 `history[i].expand()` 逐步导航，这与 H-EMV 的“层级压缩 + 按需展开”思想一致。

### 2.2 创新一：图增强的层级记忆表示与横向语义召回

图构建模块位于 [memory_graph.py](/home/user22303471/Project/Active-H-EMV/llm_emv/memory_graph.py)。系统从原始树中自动抽取所有 `EventBasedSummary` 作为图节点，并构造多类型边：

| 边类型 | 实现方式 | 学术解释 |
|---|---|---|
| `TEMPORAL_ADJACENT` | 同一目标下连续事件 | 表示事件的局部时序邻接 |
| `CO_OBJECT` | 共享物体实例 `instance_id` | 表示对象连续性与工具/容器关联 |
| `CO_LOCATION` | 固定物体集合形成的位置签名 | 表示近似空间共现关系 |
| `SIMILAR_ACTION` | 动作 embedding 余弦相似度 | 表示行为模式相似性 |
| `CAUSAL` | 可选 LLM 推断 | 表示高阶因果或动机关联 |

图检索模块位于 [graph_augmented_search.py](/home/user22303471/Project/Active-H-EMV/llm_emv/graph_augmented_search.py)。最新重构后，它已经从单纯 re-ranking 升级为真正的“初始召回 + 图邻居扩展 + 联合重排”机制：

```text
S0 = BaseRetrieval(query)
S1 = GraphExpand(S0, MemoryGraph)
score(q, n) = alpha * semantic_score(q, n)
            + beta  * graph_score(q, n)
            + gamma * depth_bonus(n)
return TopN(S0 union S1)
```

这里的关键贡献是：即使某个事件自身文本与查询相似度低，只要它与高相似度 seed 节点存在时间、物体、位置或动作关联，也能被图结构拉入候选池。该机制直接弥补了原始 H-EMV 树结构横向语义断裂的问题。

### 2.3 创新二：在线两阶段混合检索机制

检索系统由 [setup.py](/home/user22303471/Project/Active-H-EMV/llm_emv/setup.py)、[interactive_tree.py](/home/user22303471/Project/Active-H-EMV/llm_emv/interactive_tree.py)、[faiss_search.py](/home/user22303471/Project/Active-H-EMV/llm_emv/faiss_search.py) 与 [graph_augmented_search.py](/home/user22303471/Project/Active-H-EMV/llm_emv/graph_augmented_search.py) 共同组成。

原始检索使用 embedding 相似度、top-p 与 `min_cos_sim` 过滤；在配置中启用图增强后，`search_filter_kwargs` 会注入 `_memory_graph`、`_graph_embedding_fn` 以及图检索权重。我们已经修复了递归构建子节点时参数丢失的问题，使图增强配置能从根节点透传到子树检索。这一点很重要，因为 H-EMV 的问答过程本质上是多轮递归展开，如果图检索只在根层生效，实际效果会被严重削弱。

当前图增强检索还支持查询意图选择：因果问题激活 `CAUSAL` 与 `TEMPORAL_ADJACENT`，位置问题激活 `CO_LOCATION`，物体问题激活 `CO_OBJECT`，一般问题激活非因果边。这使系统从固定检索策略转向 query-adaptive retrieval。

### 2.4 创新三：效用引导的渐进式记忆巩固与遗忘

遗忘模块位于 [memory_consolidation.py](/home/user22303471/Project/Active-H-EMV/llm_emv/memory_consolidation.py)。其学术定位是 Utility-Based Progressive Forgetting，即基于记忆效用的渐进式巩固机制。

效用函数为：

```text
U(n) = alpha * Recency(n)
     + beta  * Uniqueness(n)
     + gamma * Importance(n)
```

其中 `Recency` 借鉴艾宾浩斯时间衰减，`Uniqueness` 通过节点 embedding 与其他节点的平均距离衡量语义独特性，`Importance` 综合用户对话、失败状态、目标状态变化以及图度中心性。遗忘策略分为三级：Level 0 完整保留，Level 1 删除图像和声音等重感知数据，Level 2 压缩为摘要保留。系统还设有免疫规则：包含用户对话或失败状态的节点不会被遗忘，目标首尾事件也受到保护。

这一模块的学术意义在于：它不是简单裁剪历史，而是将“长期记忆维护”建模为效用优化问题；同时使用图度中心性作为结构重要性，使记忆图不仅服务检索，也服务记忆巩固。

### 2.5 创新四：反馈驱动的闭环记忆修正与错误传播抑制

修正模块位于 [memory_correction.py](/home/user22303471/Project/Active-H-EMV/llm_emv/memory_correction.py)，评测入口位于 [qa_eval.py](/home/user22303471/Project/Active-H-EMV/llm_emv/eval/qa_eval.py) 与 [__main__.py](/home/user22303471/Project/Active-H-EMV/llm_emv/eval/__main__.py)。

其核心机制包括四步：错误定位、LLM 辅助修正、摘要覆盖、错误传播检测。摘要覆盖通过给节点挂载 `_summary_override` 实现，不直接破坏底层原始数据；[emv_api.py](/home/user22303471/Project/Active-H-EMV/llm_emv/emv_api.py) 的检索 embedding 和 [interactive_tree.py](/home/user22303471/Project/Active-H-EMV/llm_emv/interactive_tree.py) 的展示逻辑都会优先读取修正摘要。

我们刚刚进一步升级了修正触发策略：`is_answer_correct` 先做本地 exact/substring 快速判断；未命中时再调用 LLM Semantic Judge，并要求输出 `CORRECT`、`PARTIAL` 或 `WRONG`。只有确认为 `WRONG` 时才触发修正，`PARTIAL` 或信息冗余均保守跳过。这解决了 ROUGE-L 对自然语言摘要和动作列表重合度过严的问题，避免把正确或可接受的摘要误判为错误，从而污染记忆。

## 3. 学术叙事总结

本项目可以围绕“从被动层级记忆到主动可维护记忆”展开论文主线。原始 H-EMV 证明了层级摘要对长期机器人经验 verbalization 的有效性，但它更接近静态的树形存储：记忆被编码后主要等待检索，缺乏横向联想、长期维护与反馈修正能力。

Active-H-EMV 的贡献可以表述为三层递进：

第一，结构层面：在不破坏 H-EMV 层级树的基础上，引入自动派生的事件关联图，使系统同时具备纵向时间抽象与横向语义联想。

第二，检索层面：将检索从纯向量匹配扩展为“语义种子召回 + 图邻居扩展 + 联合重排”，提升对跨目标、跨时间、跨物体关联问题的召回能力。

第三，生命周期层面：引入记忆巩固与反馈修正，让系统能够对长期经验进行效用评估、渐进式压缩，并在收到反馈后抑制错误传播。

因此，论文标题可考虑：

```text
Active-H-EMV: Graph-Augmented, Utility-Consolidated, and Feedback-Corrected Episodic Memory Verbalization for Long-Term Robot Experience
```

中文题目可考虑：

```text
面向长期机器人经验语言化的主动层级情景记忆框架：图增强检索、效用巩固与反馈修正
```
