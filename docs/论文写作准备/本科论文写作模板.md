## 摘要（中英文各一份）

### 写作结构（建议400–600字）

```
[背景] 1–2句：交代领域现状与核心挑战，说明"为什么这个问题重要"。

[问题] 1–2句：指出现有方法/技术的不足，即研究动机。

[工作] 分条列举本文主要贡献（通常2–3条），格式参考：
  （1）提出……方法/框架，利用……技术，实现……目标。
  （2）提出……机制，从……和……两个层面构建……，使得……。

[结果] 给出核心量化实验指标：精度、压缩比、时延降低倍数等。

[结论] 1句：总结本工作的价值与可扩展性。
```

### 关键词
4–6个，逗号分隔，涵盖：平台/场景词 + 核心技术词 + 目标词

**示例：** 微控制器，模型压缩，情境自适应，软硬协同

## 第一章 绪论

### 1.1 研究背景
- 领域宏观趋势（2–3段）：说明技术发展方向及其重要性
- 核心矛盾引出：现有方案在目标场景下的局限（存储/计算/功耗等）
- 细分问题定位：本文聚焦的具体平台/场景（如微控制器）

> **写作技巧：** 用具体数字增强说服力。例如：
> "AlexNet 具有 0.61 亿个网络参数，需花费 240MB 的内存存储；
> 而主流 STM32 微控制器仅具备不超过 2MB 的持久性存储空间。"

### 1.2 [细分场景介绍]（可选节）
- 对部署平台/应用场景进行专项介绍
- 包括：定义、发展历史、核心优势、应用领域
- 说明在此场景下部署的挑战与机遇

### 1.3 研究目的及研究内容
- 研究动机（承接1.1的问题）
- 核心挑战（通常2项）
- 研究内容概述（分条，与摘要"工作"部分对应）

### 1.4 本文内容安排
对每章内容进行一句话概述，格式：

```
第X章[章名]，[本章主要做了什么]。
```

## 附：论文写作注意事项

### 结构一致性
- 摘要"工作"条目 ↔ 1.3"研究内容" ↔ 各核心章节 ↔ 5.1"工作总结"，四处应保持对应
- 每章"引言"节应承接上章，预告本章内容

### 数据呈现
- 关键对比结果用**表格**，变化趋势用**折线图**，结构示意用**流程图/架构图**
- 数字尽量精确到小数点后2位，单位统一

### 公式规范
- 公式独立成行，右侧标注编号：`(章-序号)`，例如 `(3-1)`
- 公式中每个符号在首次出现时需在正文中说明含义

### 图表规范
- 每张图/表需在正文中有对应引用（"如图X.X所示"/"见表X-X"）
- 图题置于图下方，表题置于表上方
- 图表编号格式：`图3.1`、`表2-1`

### 写作风格
- 避免"我认为"、"我们觉得"等主观表述，改用"本课题"、"本文"
- 重要结论/创新点可适当**加粗**强调
- 章节间需有过渡句，避免内容突兀跳转
