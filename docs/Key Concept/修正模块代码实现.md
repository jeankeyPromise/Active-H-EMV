### 核心架构

```
Agent 回答 Q₁ → 得到 hypothesis
       │
       ├── run_evaluation_with_correction 检测 episode 边界
       │   └── 同 episode 内共享 shared_history
       │
       └── correction_pipeline(shared_history, Q₁, hypothesis, ground_truth)
            │
            ├── 1. localize_error() — 语义匹配定位出错节点
            │      嫌疑度 = error_sim × 0.6 + (1 - correct_sim) × 0.4
            │
            ├── 2. correct_node_with_llm() — LLM 生成修正摘要
            │      回退: _simple_text_correction() 文本替换
            │
            ├── 3. apply_summary_override() — 挂载 _summary_override
            │      清除 _embedding_cache → 下次搜索重算
            │
            └── 4. detect_error_propagation() — 时间邻居传播检测
                   auto_propagate_correction() — 自动传播修正
```

### 使用方式

```bash
# 标准评测（无修正，现有方式不变）
python -m llm_emv.eval --cfg teach/simplified/full_graph_aug --output result.json ...

# 启用修正的评测
python -m llm_emv.eval --cfg teach/simplified/full_graph_aug_correction --output result_correction.json --enable-correction ...
```
