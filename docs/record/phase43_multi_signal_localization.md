# Phase 43: 多信号错误定位算法验证

## 实验做什么

Phase 40 使用纯语义双探针公式（`0.6·sim_error + 0.4·(1-sim_correct)`）进行错误定位，在 L4+ 层注入节点上的排名仅为 2097/6232。这一结果暴露了纯语义匹配的根本局限：它完全忽略了时间约束（错误节点不可能在提问时刻之后）、Agent 实际访问轨迹（未访问的节点实际影响力为零）和节点层级信息密度差异（L4+ 信号稀释严重）。

本轮验证第五章 5.2.1 中重新设计的**多信号嫌疑度排序算法**，对比新旧算法在定位已知注入节点上的排名差异。

## 实验如何设计

### 新算法（式 5-1）

```
suspicion(n) = 0.40·S_sem + 0.30·S_temp + 0.15·S_access + 0.15·S_density
```

四个分项：
- **S_sem**：语义差异分——sigmoid(error_sim − correct_sim)
- **S_temp**：时间邻近度——硬约束（排除 t > t_q）+ 指数衰减 e^(-|t_q−t_n|/τ)
- **S_access**：Agent 访问轨迹——实际展开/搜索过的节点优先（1.0 vs 0.2）
- **S_density**：信息密度——L2=1.0, L3=0.7, L4+=0.4

### 注入设置

在 |h|=50 的首个 batch 上，同时注入两处错误：
1. **HLS 注入**（L4+ HigherLevelSummary, depth=4）：`"...retrieved a loaf of bread from the lower cabinet..."` → 将 "cabinet" 替换为 "fridge"
2. **L2 注入**（EventBasedSummary）：`"Say("where is the bread")...Cabinet_2..."` → 将 "Cabinet" 替换为 "Fridge"

QA：question = "Where did you retrieve the bread from?" / wrong = "fridge" / correct = "cabinet"

### Agent 访问模拟

由于无法在离线实验中真实运行 Agent，采用两阶段近似：
1. 语义搜索 top-40 个与问题最相关的节点
2. 提问时间前后 2 天窗口内的所有节点
3. 两者并集作为 Agent 访问轨迹

## 结果如何

### 排名对比

| 注入节点 | 旧算法排名 | 新算法排名 | 提升 |
|---------|----------|----------|------|
| HLS (L4+, depth=4) | 2064/6232 (33.1%) | **132/6232 (2.1%)** | **+1932 位** |
| L2 (EventBasedSummary) | 4037/6232 (64.8%) | **111/6232 (1.8%)** | **+3926 位** |

### 时间约束验证（最关键的发现）

| 指标 | 旧算法 | 新算法 |
|------|--------|--------|
| 总节点中时间晚于提问时刻（未来节点） | 6081/6232 (97.6%) | 6081/6232 (97.6%) |
| Top 10 排名中的未来节点 | **10/10** | **0/10 ✓** |

旧算法的 Top 10 嫌疑节点**全部是提问时刻之后的未来节点**——这些节点在因果上不可能影响 Agent 的回答。纯语义搜索被语义上包含 "Fridge" 关键字的未来事件节点所吸引，完全忽略了时间约束。新算法通过 S_temp 硬约束将这些节点全部排除。

### 消融分析

逐步移除信号观察排名退化（目标节点：HLS L4+）：

| 配置 | HLS 排名 | Δ vs full |
|------|---------|----------|
| full (4-signal) | 132 | baseline |
| −S_density | 133 | +1 |
| −S_temp | 1559 | +1427 |
| S_sem only | 2064 | +1932 |
| −S_access | 5680 | +5548 |

- **−S_access 退化最严重**（+5548 位）：Agent 访问轨迹是区分"语义相关但 Agent 实际未接触"和"语义相关且 Agent 实际使用了"的关键信号
- **−S_temp 退化显著**（+1427 位）：时间邻近度在 97.6% 的节点都是未来节点的背景下极为重要
- **−S_density 影响最小**（+1 位）：信息密度分在当前场景下贡献有限，因为注入节点本身是 L4+

## 结果说明了什么

1. **时间约束是错误定位中最基本也最容易被忽略的信号。** 旧算法在无时间约束的情况下，Top 10 全部被未来事件占据——这些节点语义上包含错误关键词但因果上不可能导致错误。新算法通过 S_temp 的硬约束（排除 t > t_q 的未来节点）和软引导（指数衰减），从根本上解决了这一无效排序问题。

2. **Agent 访问轨迹是区分"嫌疑"和"真凶"的关键。** 在消融分析中，移除 S_access 导致的退化最为严重（+5548 位）。这验证了核心直觉：一个语义上与错误高度匹配但 Agent 从未访问过的节点，其实际影响力为零；反之，Agent 实际展开过的节点即使语义嫌疑度不是最高，也应该是优先排查对象。

3. **多信号融合显著缩小了搜索空间。** L2 注入节点在旧算法下排名 4037（几乎垫底），新算法将其提升至 111（前 1.8%）。HLS 注入节点从 33.1% 提升至 2.1%。两个注入节点的排名均进入了前 2%，说明新算法能够有效定位不同类型的记忆错误。

4. **L4+ 层的信号稀释仍是根本瓶颈。** 即使在新算法下，HLS 注入节点排名 132（前 2.1%）而非更靠前，因为高层节点的递归索引内容包含大量子节点的正确文本，稀释了单个词的错误信号。这一限制可以通过阶段二的 LLM 辅助修正来弥补——修正 LLM 可以在候选集中通过语义理解区分真正需要修正的内容。
